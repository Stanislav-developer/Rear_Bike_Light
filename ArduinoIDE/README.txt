Спершу встановіть ядро для роботи з ATtiny13:

Установка ядра MicroCore в Arduino IDE
Для роботи MicroCore потрібна версія Arduino IDE не нижче 1.6.13.
Інструкція з встановлення:

1.Відкрийте Arduino IDE.

2.Перейдіть у меню Файл → Налаштування.

3.У поле Додаткові URL-адреси менеджера плат вставте наступне посилання:

https://mcudude.github.io/MicroCore/package_MCUdude_MicroCore_index.json

4.Відкрийте меню Інструменти → Плата → Менеджер плат...

Дочекайтеся, поки завершиться завантаження індексів платформ.

5.Прокрутіть список вниз, знайдіть пункт MicroCore та натисніть на нього.

6.Натисніть кнопку Встановити.

7.Після завершення встановлення закрийте вікно менеджера плат.

Перед записом скетчу в мікроконтролер переконайтеся що у вас виставлені такі налаштування у вікні tools(інструменти):

Board(плата): ATtiny13 (MicroCore → ATtiny13)
BOD: BOD 2.7
EEPROM: EEPROM retained
Clock: 9.6 MHz

Programmer(програматор): USBasp або Arduino as ISP(Якщо ви прошиваєте через плату Arduino UNO,NANO)

Перед прошивкою рекомендується спершу записати Bootloader у мікроконтролер(для цього у самому низу натисніть Burn Bootloader (Записати завантажувач)

Тепер можна завантажити прошивку:
(Вікно Sketch → Upload Using Programmer)

Готово!
