Перед початком переконайтеся що у вас втановлено Visual Studio Code та PlatformIO актуальної версії.
Також переконайтеся щоб був встановлений драйвер на USBasp програматор.

1. Завантажте архів репозиторію за цим посиланням: https://github.com/Stanislav-developer/Rear_Bike_Light/archive/refs/heads/main.zip
2. Розпакуйте папку PlatformIO на робочий стіл або у інше зручне місце на комп'ютері.
3. У VS Code на лівій бічній панелі відкрийте розширення PlatformIO.
4. Натисніть Pick a folder та виберіть папку PlatformIO яку ви розпакували з архіву.
5. На лівій бічній панелі знову натисніть на іконку PlatformIO.
6. У меню QUICK ACCES → Miscellaneous виберіть: PlatformIO Core CLI (У вас повинен відкритися термінал PlatformIO).
7. Підключіть програматор USBasp з мікроконтролером до комп'ютеру.
8. Тепер переходимо до запису ф'юзів та прошивки в ATtiny13:
   -----------------------------------------------------------------
   Щоб завантажити 1 варіант прошивки у мікроконтролер, введіть такі команди:

   Записуємо ф'юзи:
   pio run -e firmware_1 -t fuses
   
   Записуємо прошивку:
   pio run -e firmware_1 -t upload

   -----------------------------------------------------------------
   Щоб завантажити 2 варіант прошивки у мікроконтролер, введіть такі команди:

   Записуємо ф'юзи:
   pio run -e firmware_2 -t fuses
   
   Записуємо прошивку:
   pio run -e firmware_2 -t upload

   -----------------------------------------------------------------
   Щоб завантажити 3 варіант прошивки у мікроконтролер, введіть такі команди:

   Записуємо ф'юзи:
   pio run -e firmware_3 -t fuses
   
   Записуємо прошивку:
   pio run -e firmware_3 -t upload

Під час запису фюзів та прошивки процес повинен завершуватись з статусом SUCCESS, якщо це не так то переконайтеся що мікроконтролер надійно підключений до програматора та встановлено відповідний драйвер.
